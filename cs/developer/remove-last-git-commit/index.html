Jak odstranit poslední commit v Gitu

Správný příkaz závisí na jedné otázce: už jste commit odeslali (push)? Začněte bezpečnými variantami.

Ještě neodesláno: vrátit commit, změny ponechat

git reset --soft HEAD~1

Commit je pryč a jeho změny jsou znovu připravené k commitu (staged). Pomocí git reset HEAD~1 je z přípravy vyjmete také.

Ještě neodesláno: vrátit commit a změny zahodit

git reset --hard HEAD~1

Už odesláno do sdílené větve

Vytvořte nový commit, který ten starý zruší. Historie zůstane všem zachována:

git revert HEAD
git push

Jen zpráva je špatně

git commit --amend

Přepsání odeslané větve, která je vaše

Jen pokud ji nikdo jiný nepoužívá:

git reset --hard HEAD~1
git push --force-with-lease

Pozor: --hard maže nezapsanou práci. Pokud omylem odstraníte commit, git reflog vypíše poslední stavy a git reset --hard <hash> vás vrátí zpět.

Otázky

Co znamená HEAD~1?

Ukazuje na commit před aktuálním. HEAD~3 jde o tři commity zpět.

Proč je force push riskantní?

Přepíše historii na vzdáleném serveru. Kolegové, kteří už starý commit stáhli, narazí na konflikty.

How to delete a page in Word

Select everything on the page and delete it. If the page is blank and will not go away, a hidden paragraph mark or page break is usually the cause.

Delete a page with content

  1. Click anywhere on the page you want to delete.
  2. Press Ctrl + G (Mac: ⌥ + ⌘ + G) to open Go To.
  3. Type \page and press Enter, then Close. The whole page is selected.
  4. Press Delete.

Delete a blank page at the end

  1. Press Ctrl + Shift + 8 (Mac: ⌘ + 8) to show paragraph marks (¶).
  2. Select the extra paragraph marks or the Page Break line on the blank page.
  3. Press Delete until the page is gone.

If the blank page follows a table, the last paragraph mark cannot be deleted. Select it and set the font size to 1 pt, or hide it with Ctrl + D, Hidden.

In Google Docs

Select the text on the page and press Delete. If a blank page remains, check Insert, Break for an unwanted page break, or reduce the spacing before the final paragraph.

Tip: Before you delete, save a copy. Undo (Ctrl + Z) also brings the page back.

Questions

Why does a blank page appear before my table?

Word needs a paragraph after a table. If the table ends exactly at the bottom of a page, that paragraph moves to the next page.

Will deleting a page change the page numbers?

Yes. The following pages move up and numbering updates automatically.

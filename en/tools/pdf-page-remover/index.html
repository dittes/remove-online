Remove pages from a PDF

Delete the pages you do not need and optionally wipe the document’s hidden details. The file stays on your device.

Loading the tool…

Runs in your browser. Your files are never uploaded.

How it works

Choose a PDF, type the pages to delete (for example 2, 4-6) and download the new file. The result is built from the pages you keep, so the removed pages are really gone from the file and not just hidden.

Tick Remove metadata to blank the title, author, creator and producer, and drop the XMP block. You can use it without deleting any page.

Links, bookmarks and form fields that point to removed pages may stop working. Password-protected PDFs have to be unlocked first; see how to remove a password from a PDF.

Questions

Is the PDF uploaded?

No. The file is read and rewritten by your browser with the open-source pdf-lib library, served from this site.

Why did the file size not shrink much?

The remaining pages keep their images and fonts. Only what the removed pages alone used is dropped.

Can I remove a page from an encrypted PDF?

Not here. Open it with the password in your browser or viewer, save an unlocked copy, then use this tool.

Remove metadata from a PDF

See the title, author and creator stored in a PDF and wipe them. The file stays on your device.

Loading the tool…

Runs in your browser. Your files are never uploaded.

How it works

Choose a PDF. The tool shows the title, author, creator and producer stored in it. With Remove metadata ticked (it is by default here), it builds a new file without them and without the XMP block, and you download the clean copy.

You can also delete pages in the same step. Content such as text, images and any visible names inside the pages is not changed.

Questions

What does PDF metadata contain?

Typically the title, author, subject, keywords, the program that created it, the PDF producer and creation and modification dates.

Does it remove hidden text or comments?

No. It clears document properties. Annotations and the page content stay.

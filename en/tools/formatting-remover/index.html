Remove formatting: convert text to plain text

Paste text from Word, a web page or an e-mail and get clean plain text without fonts, colours or HTML tags.

Loading the tool…

Runs in your browser. Your files are never uploaded.

How it works

A plain text box drops fonts, colours and styles the moment you paste into it. The options go further: Remove HTML tags turns page source into readable text (scripts and styles are discarded), Straight quotes and Plain dashes replace typographic characters that cause trouble in code and forms, and Plain bullets converts •-style bullets to dashes.

Non-breaking spaces and zero-width characters, which often arrive with copied text, are removed by default.

Questions

Does it keep paragraphs?

Yes. Line breaks and blank lines stay. Use the text cleaner to join lines.

Is HTML executed?

No. Tags are parsed as inert text and only the text content is kept.

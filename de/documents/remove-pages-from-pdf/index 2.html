Seiten aus einem PDF entfernen

Sie müssen nichts installieren und kein Dokument hochladen. Ihr Mac, Ihr Browser oder Adobe Acrobat können Seiten direkt aus einem PDF löschen.

Ohne Umwege direkt hier erledigen: PDF-Seiten entfernenTool öffnen

Auf dem Mac mit der Vorschau

  1. Öffnen Sie das PDF in der Vorschau.
  2. Wählen Sie Darstellung, dann Miniaturen.
  3. Klicken Sie die Seite an, die Sie löschen möchten (mit ⌘ wählen Sie mehrere aus).
  4. Drücken Sie Entf und sichern Sie mit ⌘ + S.

Unter Windows, Mac oder Linux mit Chrome oder Edge

  1. Öffnen Sie das PDF im Browser und drücken Sie Strg + P (am Mac ⌘ + P).
  2. Wählen Sie als Ziel Als PDF speichern.
  3. Wählen Sie unter Seiten die Option Benutzerdefiniert und geben Sie die Seiten ein, die Sie behalten möchten, zum Beispiel 1-3, 5-8.
  4. Klicken Sie auf Speichern. Es entsteht eine neue Datei, das Original bleibt unverändert.

In Adobe Acrobat

  1. Wählen Sie Tools, dann Seiten organisieren.
  2. Markieren Sie die unerwünschten Miniaturen und klicken Sie auf das Papierkorb-Symbol.
  3. Speichern Sie die Datei.

Tipp: Über den Druckdialog geht es am schnellsten, dabei können aber Links, Lesezeichen und Formularfelder verloren gehen. Nutzen Sie dafür die Vorschau oder Acrobat.

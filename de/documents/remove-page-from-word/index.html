Eine Seite in Word löschen

Markieren Sie alles auf der Seite und löschen Sie es. Bleibt eine leere Seite hartnäckig bestehen, steckt meist eine versteckte Absatzmarke oder ein Seitenumbruch dahinter.

Eine Seite mit Inhalt löschen

  1. Klicken Sie irgendwo auf die Seite, die Sie löschen möchten.
  2. Drücken Sie Strg + G (Mac: ⌥ + ⌘ + G), um Gehe zu zu öffnen.
  3. Geben Sie \page ein, drücken Sie Enter und dann Schließen. Die ganze Seite ist markiert.
  4. Drücken Sie Entf.

Leere Seite am Ende löschen

  1. Drücken Sie Strg + Umschalt + 8 (Mac: ⌘ + 8), um Absatzmarken (¶) anzuzeigen.
  2. Markieren Sie die überzähligen Absatzmarken oder die Zeile Seitenumbruch auf der leeren Seite.
  3. Drücken Sie Entf, bis die Seite verschwunden ist.

Folgt die leere Seite auf eine Tabelle, lässt sich die letzte Absatzmarke nicht löschen. Markieren Sie sie und stellen Sie die Schriftgröße auf 1 pt, oder blenden Sie sie mit Strg + D, Ausgeblendet aus.

In Google Docs

Markieren Sie den Text auf der Seite und drücken Sie Entf. Bleibt eine leere Seite, prüfen Sie unter Einfügen, Umbruch auf einen ungewollten Seitenumbruch oder verkleinern Sie den Abstand vor dem letzten Absatz.

Tipp: Speichern Sie vor dem Löschen eine Kopie. Mit „Rückgängig“ (Strg + Z) kommt die Seite ebenfalls zurück.

Fragen

Warum erscheint eine leere Seite hinter meiner Tabelle?

Word braucht nach einer Tabelle einen Absatz. Endet die Tabelle genau am Seitenende, rutscht dieser Absatz auf die nächste Seite.

Ändern sich durch das Löschen die Seitenzahlen?

Ja. Die folgenden Seiten rücken nach, die Nummerierung wird automatisch aktualisiert.

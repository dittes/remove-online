Docker-Images und -Container entfernen

Stoppen und entfernen Sie zuerst Container, dann Images. Prune-Befehle räumen in großen Mengen auf – lesen Sie, was sie löschen werden.

Einen Container entfernen

docker ps -a
docker stop <container>
docker rm <container>

Mit docker rm -f <container> stoppen und entfernen Sie einen laufenden Container in einem Schritt.

Ein Image entfernen

docker images
docker rmi <image>

Docker verweigert das Entfernen eines Images, das noch von einem Container genutzt wird – entfernen Sie zuerst diesen Container.

Gesammelt aufräumen

docker container prune
docker image prune
docker system prune

docker system prune entfernt gestoppte Container, ungenutzte Netzwerke, „dangling“ Images und den Build-Cache. Mit -a entfernen Sie alle ungenutzten Images, mit --volumes auch Volumes.

Achtung: Volumes enthalten Daten wie Datenbanken. Sie werden nur mit --volumes entfernt, und das lässt sich nicht rückgängig machen.

Fragen

Was ist ein „dangling“ Image?

Ein Image ohne Tag, meist übrig geblieben, wenn Sie ein Image unter demselben Namen neu gebaut haben.

Wie entferne ich alles?

Mit docker rm -f $(docker ps -aq) alle Container, danach mit docker rmi $(docker images -q) alle Images. Prüfen Sie vorher die Listen.

Verwandte Anleitungen

  • Ein Verzeichnis unter Linux löschen
  • Letzten Git-Commit entfernen
  • Zeilenumbrüche entfernen

Ein Verzeichnis unter Linux löschen

Auf der Kommandozeile gibt es keinen Papierkorb. Wissen Sie, welchen Befehl Sie brauchen, und prüfen Sie den Pfad, bevor Sie Enter drücken.

Ein leeres Verzeichnis

rmdir meinordner

Ein Verzeichnis mit Dateien

rm -r meinordner

Mit -i werden Sie vor jedem Löschen gefragt: rm -ri meinordner.

Ohne Rückfragen

rm -rf meinordner

-f überspringt Nachfragen und ignoriert fehlende Dateien. Nutzen Sie es nur, wenn Sie sicher sind.

Passende Ordner überall löschen

Zum Beispiel jeden node_modules-Ordner unterhalb des aktuellen Verzeichnisses (zuerst mit -print prüfen):

find . -name node_modules -type d -prune -print
find . -name node_modules -type d -prune -exec rm -rf {} +

Achtung: Führen Sie nie rm -rf / aus und fügen Sie keine Befehle ein, die Sie nicht verstehen. Ein verirrtes Leerzeichen wie in rm -rf / home ändert die Bedeutung völlig. Prüfen Sie den Pfad vorher mit ls.

Fragen

Warum erhalte ich „Permission denied“?

Das Verzeichnis gehört Ihnen nicht. Prüfen Sie es mit ls -ld meinordner. Nutzen Sie sudo nur, wenn Sie sicher sind, dass der Pfad stimmt.

Bekomme ich die Dateien zurück?

Meist nicht. Gelöschte Dateien landen nicht im Papierkorb. Stellen Sie sie aus einem Backup wieder her.

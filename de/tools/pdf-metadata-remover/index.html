Metadaten aus einem PDF entfernen

Sehen Sie, welche Angaben zu Titel, Autor und Ersteller in einem PDF stecken, und löschen Sie sie. Die Datei bleibt auf Ihrem Gerät.

Tool wird geladen …

Läuft in Ihrem Browser. Ihre Dateien werden nie hochgeladen.

So funktioniert es

Wählen Sie ein PDF. Das Tool zeigt Titel, Autor, Ersteller und Produzent, die darin gespeichert sind. Mit aktiviertem Metadaten entfernen (hier standardmäßig an) baut es eine neue Datei ohne diese Angaben und ohne XMP-Block, die Sie als saubere Kopie herunterladen.

Im selben Schritt können Sie auch Seiten löschen. Inhalte wie Text, Bilder und sichtbare Namen auf den Seiten werden nicht verändert.

Fragen

Was enthalten PDF-Metadaten?

Meist Titel, Autor, Thema, Schlüsselwörter, das erstellende Programm, den PDF-Produzenten sowie Erstellungs- und Änderungsdatum.

Werden versteckter Text oder Kommentare entfernt?

Nein. Es werden die Dokumenteigenschaften geleert. Anmerkungen und Seiteninhalt bleiben.

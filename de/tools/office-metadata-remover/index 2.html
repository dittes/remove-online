Remove personal information from Word, Excel and PowerPoint files

Blank the author, last editor, company and other properties in .docx, .xlsx and .pptx files before you share them.

Tool wird geladen …

Läuft in Ihrem Browser. Ihre Dateien werden nie hochgeladen.

So funktioniert es

Drop one or more Word, Excel or PowerPoint files. The tool lists the properties it found (author, last modified by, title, subject, keywords, comments, category, company, manager) and gives you a copy with those fields emptied.

It can also remove the preview thumbnail and reset the created and modified dates. Tracked changes, comments inside the text and custom properties are not touched; for those use File → Info → Inspect Document in Office.

Fragen

Does the document still open normally?

Yes. Only text fields in the document properties are emptied; the content is copied unchanged.

What about .doc, .xls and .ppt?

Only the modern formats (docx, xlsx, pptx) are supported. Save older files in the new format first.

Are my files uploaded?

No. They are opened and rewritten by your browser.
